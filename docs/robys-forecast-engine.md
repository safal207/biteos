# Robys Predictive Intelligence v0.1
Local next-day sold-unit forecast for one existing SKU, no upload, storage or external API. Pages synthetic only. Input schema biteos.robys-sales-history.v1, tenant robys, source operator-reconciled-pos, exact pinned catalog revision, existing product ID, weatherBasis declared-pre-day-scenario, 56–112 complete consecutive days ending yesterday (Istanbul local) of {day,units,availableAllDay,weather,occasion}. Weather and occasion must have been recorded before each day; provenance is declared, not verified. Units reconciled after refunds by operator, comparable opening hours/prices/assortment assumed; no customer records. Exclude closed, partial availability/stockout and storm days; sales are not total demand. Missing dates rejected. Baseline = mean of up to 12 previous same-weekday available observations (minimum 4); contextual candidate = subset with same weather and occasion flag (minimum 3). Last 14 days rolling one-day backtest; uses only earlier days per prediction. Report MAE and WAPE; context compared with baseline on same matched days. Require ≥10 observations and WAPE ≤35% to show each respective candidate (heuristic review thresholds, not calibrated policy). Target storm => abstain. No automatic model selection or promotion based on holdout; an independent future validation needed. Range = point ± max observed absolute error, clipped at zero, not calibrated predictive interval or guarantee. No prices, staffing or procurement decisions; no causality, no live weather, no verified POS. Real demand needs stockout/capacity modelling and prospective validation. Example synthetic alternating weather weeks with different unit volumes. No new dependencies. Draft only.
