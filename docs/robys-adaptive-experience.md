# My Robys — Adaptive Experience v0.1

A separate interactive draft at #retail-robys-experience. Six guest-controlled presentation modes: standard, cozy, study, friends, family, fresh. Different palette, hero, one catalog product and at most one opt-in companion. Exact catalog prices, no discount or checkout mutation; budget/stock and safety guard boundaries in pure model. Weather is manual and date/time fixed for simulation. Standard menu remains a visible link; no customer profiling. Explicit discovery preview (three non-purchase activities, no rewards, no persisted streak). Share link includes only allowlisted theme, no IDs, progress or history; recipient can change mode. UI localization TR/RU/EN. No new dependencies. Does not modify live Robys.
 
References: SamCart Order Bump Suggestions https://help.samcart.com/support/solutions/articles/60001648747-order-bump-suggestions (observed purchase pairs, draft review); ClickFunnels https://support.clickfunnels.com/en/articles/12733909-creating-an-order-bump-product (single contextual add-on); Duolingo https://blog.duolingo.com/product-highlights/ and https://blog.duolingo.com/streak-milestone-design-animation/ (seasonality, quests, share cards). This prototype uses curated pair hypotheses, not real purchase association mining. Next: validate animations/theme accessibility, live inventory, context ranking and consented preference storage; verified cross-sell association with minimum sample and owner approval, event telemetry and A/B tests. No claim of conversion uplift. No purchase streak or pressure to visit/spend. No paid SDK. Campaign Studio mobile overflow fix is a width constraint, to be verified by exact-head CI.

## v0.2
Calendar-linked seasonal overlay, editable scenario date/hour, optional Halloween/Christmas switch, and locally generated 1080×1920 PNG story. Native Canvas API only; fixed branding and public mood/season labels, no personal data or externally hosted image. The link intentionally still shares just the public mood, not date or seasonal setting; the screenshot/card carries the visible seasonal look. Explicit mode is no longer silently overridden by weather. The context guard suppresses offers when blocked or date invalid; standard menu always visible. Seasonal overlay changes palette and headline, not catalog prices or actual stock, and does not replace the curated cross-sell yet. Campaign layout fix uses definite grid columns and logs overflow offenders in CI; verification pending. No public Robys deployment.

## v0.3 Social browsing patterns
Four independently selectable layouts (classic list, short single-item feed, photo wall, category collections) over the same eleven verified local Robys images. Inspired by familiar social interaction patterns; no platform branding, embedded video, scraping, social account or inferred demographics. Each layout can coexist with a guest's mood. Share URL allowlists mood plus layout only. Local optional test feedback counts selection, deliberate next/previous actions, menu link clicks and one changeable explicit like/dislike per layout; counts bounded, no identifiers, storage, network or ingestion. A suggestion is displayed only if exactly one layout has an explicit positive vote; nothing changes automatically. Withdrawal clears local counters. Click is not confirmed arrival, purchase or preference beyond this session. No real guest data collection. Future opt-in, versioned exposure and trustworthy aggregate outcome comparison; custom styles later. Mobile WebKit overflow containment added at individual campaign section, not page; CI pending.

## v0.4 Personal style builder
Six palette choices (including automatic), two card densities, optional discovery display. Curated palettes override visual colors, including PNG story, while calendar labels and safety gates remain intact. Strict three-field device storage only on explicit Save; Forget removes the saved record (current on-screen settings remain until reset or reload). Default resets current appearance without changing saved settings; edits are not automatically persisted. Public link includes allowlisted mood, layout and style codes; valid complete shared style overrides device settings for this visit only, never writes storage. No identity, tracking history, demographics or free-form CSS. Contextual style count is at most 6 moods × 4 layouts × 6 palettes × 2 densities × 2 discovery settings = 576 combinations, not distinct validated designs. Single explicit positive layout vote yields suggestion; guest may apply it, no automatic switching. Feedback stays in memory, withdrawal clears it. CI adds shared-code, storage lifecycle, UI suggestion and mobile checks. Public café site unchanged.
