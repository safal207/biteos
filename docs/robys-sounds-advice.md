# Roby's Sounds → Living Brand Agent

Stacked on BiteOS #3. Source-boundary rehearsal for Robys #505 at
`3d1f251ebf362009273b0c0c437f4076171b48de`, sounds-model blob `7b07c4686f08f5120e59d8f6a568b75fc5428140`.

A single explicit moment maps into the existing context engine:
morning → any, focus → study, calm/evening → quiet, friends → friends.
These are editorial mappings, not inferred behaviors. Adaptive design
codes remain aligned with the existing UI. Music style and layout are
presentation only and are not accepted by this advice boundary.

The strict request sends only a guest-selected moment, explicitly chosen
favorite/avoid item IDs, a catalog revision, scenario availability,
manual weather, time and optional budget. No automatic selection from saved
look, browsing history, payment receipts, device applications or streaming
service data. Do not serialize or transport a device preference record.
An opt-out request carries null moment and empty favorites/avoids, and
abstains. With no explicit product preference the existing advice engine
also abstains. Regular menu remains available.

Existing clubAdvice and brandDecision perform ranking, price validation,
exclusions and safety gates; no new model, data store or provider.
Cross-repository CI checks the reviewed actual Sounds module's Git blob
and mood mapping, then exercises the adapter. This is not a browser or
HTTP integration. No guest UI, live data, stock, purchases, marketing,
external effects, or production activation. The editorial Sounds cards
remain distinct from actual agent advice. Confirm owner scope and browser
acceptance before any rollout. No paid dependency.
