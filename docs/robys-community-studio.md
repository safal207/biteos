# Robys Community Studio v0.1

Planning-only workspace #retail-robys-community. Select two existing catalog items and a 3–14 day tasting campaign; produce nine dated phases: story, question, dialogue, anticipation, terms, event, close, results, learning. TR/RU/EN copy and measures. Proposed first campaign: Caramel Latte vs Hazelnut Latte. Catalog names are real; event details, costs, availability, terms, and rewards are hypothetical. No claims of actual participation or results. Dates use Istanbul calendar and end exclusive.

Reward budget is a proposed operator-entered unit cost multiplied by a strict maximum number; over-budget plans cannot be downloaded in the UI. This is not total event cost or margin. Rule draft: first eligible adults, one tasting per person, no purchase or review required. Owner must explicitly confirm the selected taste, eligibility, portion, capacity, cost, allergens, consent, legal/commercial terms and fulfillment method before publishing. No chance-based draw, positive-review incentive, actual votes, customer profiling, identity capture, automated messaging, coupon issue or publication. Photos/quotes only with consent; results only after verification. Draft export contains no personal data, may be downloaded in demo or local mode; no network or persistence. No new dependencies. Campaign Studio separately generates compatible UTM links; this module does not claim attribution. Operational collection and consented loyalty integration remain separate milestones.
