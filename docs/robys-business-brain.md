# Robys Living Business Brain v0.1
Workspace #retail-robys-brain. Recomputes five existing pure engines from one strict local input bundle, not a second set of formulas or copied dashboard totals. Exact fields in robysBusinessBrain.ts (tenant robys, pinned catalog revision, same Istanbul reporting day, history/weather/occasion, ingredient plan/costs/discount/campaign, experiment and pilot). Nullable sources signal missing; invalid source is explicitly flagged, dependent financial computation blocked if operations fails. Pilot must close within last 30 days. Same-day declared inventory and costs, history ending yesterday, experiment evaluated by own horizon; sources not independently verified. Prioritize experiment error/allocation warnings, excluded stock/shortages and margins before marketing reviews, forecast abstention; absence/invalid evidence yields collect-evidence unless a hold exists. Explicit baseline forecast mismatch flags review; no automatic updating planned quantities. Negative scenario/pilot contribution is a review prompt, not causal evidence. Deterministic order: hold, collect, review, source order, code. Status review-only is NOT approval, validated data, food safety, stock feasibility or profitability. Positive experiment and commercial pilot are independent, no causal joins. No raw personal data accepted by module schemas. UI Pages uses synthetic only; local import in memory only, bounded 1 MiB, no network, auth, persistence, background work, price or stock changes, ordering or rollout. Links open separate modules and do not transfer inputs. No external dependencies. Next gate: real-data source contracts, independently reconciled owner-authorized data, secure access, staged local pilot, exact-head CI and owner review. Do not deploy public cafe.
